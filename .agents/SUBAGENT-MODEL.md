# Subagent model — HARD

Канон для **всех** оркестраторов и скиллов, которые вызывают Task / субагентов.

При любом запуске субагента (Cursor Task / Subagent):

1. **НЕ** передавать параметр `model` / `model_id` — **поле опустить целиком**.
2. Субагент **MUST** наследовать модель родительского чата.
3. Передавать `model` **только** если в **последнем** сообщении пользователя явно названа модель
   (например «запусти на sonnet», «use gpt-…»). Уточнения, skills, AGENTS и догадки
   «для качества/скорости» **не** считаются разрешением.
4. Поймал себя на выборе модели «чтобы лучше/быстрее» — **стоп**, опустить `model`.
5. Не использовать legacy / угаданные slug'и.

Always-on Cursor rule (дубль): `~/.cursor/rules/subagent-model-inherit.mdc`.
